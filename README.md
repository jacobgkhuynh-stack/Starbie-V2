Hiya, this is for Half Life week 1 it's a Starbie: basically a desktop Tamagotchi but I made it into a compact rectangle. How a Starbie works is it's basically the same thing as a Tamagotchi but you can tilt and move it to also interact with it.
So it has a 0.96in 128x64 oled display, a XIAO-ESP32-C3 as the brain, a DHT11 for temp and humidity sensing, and a MPU6050 for motion tracking.
